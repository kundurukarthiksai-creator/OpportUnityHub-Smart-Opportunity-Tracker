# OpportUnity Hub — Environment Configuration Guide

This guide will walk you through setting up your local development environment for **OpportUnity Hub** and obtaining all the required keys and credentials.

---

## Quick Start (Automatic .env Generation)

We have created an automatic setup script that copies the template and pre-generates secure cryptographic secrets for you.

1. Run the setup script in your terminal:
   ```bash
   python setup_env.py
   ```
2. Open the newly generated `.env` file at the project root.
3. Follow the instructions below to get your Supabase, Google OAuth, and AI API keys, then paste them into the `.env` file.

---

## Environment Variables Breakdown

| Variable | Description | Source / How to Get |
|---|---|---|
| `SUPABASE_URL` | The REST endpoint URL for your Supabase project. | [Supabase Console](https://supabase.com) |
| `SUPABASE_KEY` | The API Key (`anon` or `service_role` key) for database access. | [Supabase Console](https://supabase.com) |
| `JWT_SECRET` | Secret key used to sign and verify JSON Web Tokens (session tokens). | Pre-generated by `setup_env.py` |
| `ENCRYPTION_KEY` | 32-byte Base64 key used to encrypt/decrypt OAuth refresh tokens. | Pre-generated by `setup_env.py` |
| `GOOGLE_CLIENT_ID` | OAuth 2.0 Client ID for Google Authentication and Gmail Sync. | [Google Cloud Console](https://console.cloud.google.com) |
| `GOOGLE_CLIENT_SECRET` | OAuth 2.0 Client Secret corresponding to the Client ID. | [Google Cloud Console](https://console.cloud.google.com) |
| `GOOGLE_REDIRECT_URI` | The authorized redirect URI for OAuth callbacks. | `http://localhost:8000/api/auth/google/callback` |
| `GEMINI_API_KEY` | Google Gemini API key for smart scraping and categorization. | [Google AI Studio](https://aistudio.google.com) |
| `OPENAI_API_KEY` | OpenAI API key (optional alternative to Gemini). | [OpenAI Platform](https://platform.openai.com) |
| `AI_PROVIDER` | Chosen AI API model (`gemini` or `openai`). | Set to `gemini` (default) or `openai` |

## Detailed Step-by-Step Instructions

### 1. Supabase Setup (`SUPABASE_URL`, `SUPABASE_KEY`)

Supabase provides the PostgreSQL database and user table integration.

1. Go to [Supabase](https://supabase.com/) and sign up / log in.
2. Click **New Project** and select/create an organization.
3. Fill in the Project Name (e.g., `OpportUnity Hub`), database password, and region, then click **Create new project**.
4. Wait a few minutes for the database to provision.
5. Once ready, navigate to **Project Settings** (gear icon on the sidebar) -> **API**.
6. Copy the following:
   - **Project URL** -> Paste into `SUPABASE_URL`
   - **Project API keys** (`service_role` or `anon` public key) -> Paste into `SUPABASE_KEY`

> [!NOTE]
> For backend automated scraping and user syncing, the `service_role` key is recommended as it bypasses Row Level Security (RLS) policies when running system actions.

---

### 2. Google OAuth 2.0 Setup (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`)

Required for Google login and syncing student/opportunity emails via the Gmail API.

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a **New Project** or select an existing one.
3. In the sidebar, search for and go to **APIs & Services** -> **Enabled APIs & Services**.
4. Click **+ ENABLE APIS AND SERVICES**, search for **Gmail API**, and click **Enable**.
5. Go to **APIs & Services** -> **OAuth consent screen**:
   - Select **External** and click **Create**.
   - Fill in the App Name (e.g., `OpportUnity Hub`), user support email, and developer contact information.
   - Click **Save and Continue**.
   - Under **Scopes**, add `https://www.googleapis.com/auth/gmail.readonly` and `openid / email / profile` scopes.
   - Under **Test Users**, add your own email address (important! OAuth will not work for you during testing if your email is not here).
   - Click **Save and Continue**.
6. Go to **APIs & Services** -> **Credentials**:
   - Click **+ CREATE CREDENTIALS** -> **OAuth client ID**.
   - Set Application Type to **Web application**.
   - Under **Authorized JavaScript origins**, add:
     - `http://localhost:8000`
     - `http://127.0.0.1:8000`
   - Under **Authorized redirect URIs**, add exactly:
     - `http://localhost:8000/api/auth/google/callback`
   - Click **Create**.
7. Copy the **Client ID** and **Client Secret** and paste them into your `.env`.

---

### 3. Google Gemini Setup (`GEMINI_API_KEY`)

The system utilizes Gemini to automatically read email alerts, parse details, and categorize opportunities.

1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Log in with your Google account.
3. Click **Get API Key** on the top left.
4. Click **Create API Key** -> **Create API Key in new project** (or select an existing one).
5. Copy the generated API Key and paste it into `GEMINI_API_KEY`.
6. Make sure `AI_PROVIDER=gemini` is set in your `.env`.

---

### 4. Cryptographic Keys (`JWT_SECRET`, `ENCRYPTION_KEY`)

These are generated automatically by running `setup_env.py`. If you want to generate them manually:
- **JWT_SECRET**: Use a random string. You can generate one via terminal:
  ```bash
  python -c "import secrets; print(secrets.token_hex(32))"
  ```
- **ENCRYPTION_KEY**: Must be a urlsafe 32-byte Base64 key. You can generate one via terminal:
  ```bash
  python -c "import base64, os; print(base64.urlsafe_b64encode(os.urandom(32)).decode())"
  ```

## Starting the Application

Once your `.env` is fully set up:

1. Double-click the `start.bat` file in the root folder.
2. The batch file will:
   - Install all Python dependencies.
   - Start the FastAPI backend server on `http://localhost:8000`.
3. Open your browser and navigate to `http://localhost:8000` or open `frontend/index.html` to start using OpportUnity Hub!
